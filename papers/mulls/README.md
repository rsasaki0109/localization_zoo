# MULLS

`MULLS` を意識した軽量 multi-metric LOAM 実装です。

- `A-LOAM` の feature extraction + odometry を front-end に使用
- back-end で `edge + plane + point` の 3 種類の残差を同時最適化
- map は frame history を持つ sliding window として管理

full 論文の全ロバスト化や大規模 map 管理をそのまま移植したものではなく、
`multi-metric scan-to-map` の比較用コアライブラリとして置いています。

## MULLS-LO (`--mulls-lo`, 2026-10-11)

既定の `MULLS` は A-LOAM の特徴を使う軽量版で、公式実装 (YuePanEdward/MULLS) と同じ KITTI
スキャンで比べると論文値の 7.62x 離れていた。公式コード自体は論文値を再現する
(KITTI 07 で 0.311-0.332 %、論文 0.29 %) ので、差はこの実装の構造にあった。

`mulls_lo.h` の `MullsLO` は論文と著者の KITTI プロファイルから書き起こした MULLS-LO で、
公式コードは流用していない (公式は GPL-3)。`pcd_dogfooding --mulls-lo` (urban プロファイル)、
`--mulls-lo-highway` (疎な高速道路向け) で使う。既定の `MULLS` は変えていない。

| 段 | 内容 (urban プロファイル) |
|---|---|
| 入力 | 水平距離 1.5-120 m、センサー周り 1.75 m と地下の点を除去、強度は 0-255 |
| 地面 | 2.5 m グリッド。セル内の最低点から 0.25 m 以内を候補、3×3 近傍の最低点より 1.5 m 以上高いセルは非地面。セルごとに RANSAC 平面 (\|n_z\| > 0.8)。距離に反比例する間引き (10 m で 1/13、35 m 以遠は全点)、疎な集合は 800 点 |
| 非地面の分類 | 半径 0.7 m (30 m 以遠は √(r/30) 倍) の最近傍 25 点で PCA。線形性 > 0.62 で鉛直なら pillar、水平で低ければ beam。平面性 > 0.62 で鉛直面なら facade。曲率の大きい点はラベル付き近傍が多ければ pillar / beam に昇格 |
| 疎な集合 | 顕著度順の NMS (0.175 m)、pillar 400 点、facade は法線の方位 4 象限で各 300 点 |
| 位置合わせ | 最初の 2 フレームは前フレームの密な特徴へ、以降はローカルマップへ。最近傍 1 点、法線 / 方向の一致 (20°)、ゲート 1.4 m (立ち上がりは +1 m) を毎回 1.1 で割り 0.5 m まで |
| multi-metric ICP | ground / facade は点-平面、pillar (と highway の beam) は点-直線の残差を線形化して重み付き最小二乗で一度に解く。重みは地面の釣り合い (facade + 2 pillar に対する地面の対応数の比)、距離 (最初は遠い点、後で近い点を重視)、3 回目以降の Huber (δ 0.05)、強度差。最大 20 回 |
| ローカルマップ | 直前フレームの座標で保持。疎な特徴を追加、90 m で切り取り、2 万点を超えたらクラスごとに比例して間引く。動く物体の点を除去、10 フレームごとに pillar の方向を再計算 |
| 初期値 | 等速 (前フレームの相対運動) |

KITTI の HDL-64E 向けの仰角補正は公式プロファイルでは 0.195° (`--input-vertical-angle-correction-deg 0.195`)。

### 何が効いているか (KITTI 07、補正あり)

全部入りから 1 つずつ外した結果 (`--mulls-lo-disable NAME`):

| 外した要素 | RTE [%] |
|---|---:|
| なし (MULLS-LO) | 0.319 |
| ローカルマップ (`scan-to-map`、ずっと前フレームへ合わせる) | 0.758 |
| その他 (vertex-promotion, source-pruning, ground-balance, distance-weight, huber, intensity-weight, dynamic-removal, pillar-refresh) | 0.309-0.336 |

仰角補正に 1e-6° から 7e-6° を足すと 0.315-0.326 % に散る (±2 %) ので、±0.01 ポイント程度は誤差の範囲。
ローカルマップとの位置合わせだけが大きく効き、ほかの仕組みは個々には小さい。

旧実装との差は個々の重みや閾値ではなく、パイプラインそのもの (地面抽出と PCA 分類による特徴、
点-平面 / 点-直線の multi-metric ICP、ローカルマップとの位置合わせ) にあった。

### 公式実装のビルド

公式実装のビルドには PCL 1.14 / GCC 13 向けの修正が要る (`run_official_mulls_baseline.py`
の docstring を参照)。公式コードは乱数のシードを時刻から取り OpenMP を使うので、実行ごとに
少し揺れる (KITTI 07 で 0.311-0.332 %)。この実装は乱数のシードを固定しており決定的。
